# Практическая работа №2 — Полный EDA

## Вариант

**Уровень B — данные заданы**

## Цель работы

Провести полный разведочный анализ данных (EDA), изучить структуру набора данных, типы признаков, распределения числовых и категориальных признаков, выявить выбросы, исследовать корреляции и определить основные проблемы данных.

## Выполненные этапы

В ходе работы были выполнены следующие этапы:

1. Проведён общий осмотр набора данных.
2. Определены числовые и категориальные признаки.
3. Проверено наличие пропущенных значений.
4. Проверено наличие дубликатов.
5. Исследованы распределения числовых признаков с помощью гистограмм.
6. Проведён поиск потенциальных выбросов с помощью boxplot и метода IQR.
7. Исследованы частоты категориальных признаков.
8. Определены редкие категории.
9. Построена корреляционная матрица числовых признаков.
10. Построены диаграммы рассеяния для наиболее коррелирующих признаков.
11. Проверено распределение целевой переменной, если задача является классификационной.
12. Сформирован список обнаруженных проблем данных.

## Визуализация

В работе использованы следующие виды визуализации:

- гистограммы;
- boxplot;
- столбчатые диаграммы;
- корреляционная матрица;
- диаграммы рассеяния;
- график распределения целевой переменной.

## Основные проблемы данных

По результатам EDA были рассмотрены следующие возможные проблемы:

- пропущенные значения;
- потенциальные выбросы;
- неравномерное распределение некоторых числовых признаков;
- редкие категории;
- дубликаты;
- высокая корреляция между некоторыми признаками;
- возможный дисбаланс целевой переменной.
