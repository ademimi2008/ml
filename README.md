# Практическая работа №2 — EDA

## Student Performance

**Вариант:** уровень B

### Цель работы

Провести полный разведочный анализ (EDA) набора данных `Student_Performance.csv`.

### Выполненные задачи

В ходе работы были выполнены:

1. Общий осмотр набора данных.
2. Определение типов признаков.
3. Анализ числовых признаков.
4. Анализ распределения данных с помощью гистограмм.
5. Поиск потенциальных выбросов с помощью boxplot.
6. Анализ категориальных признаков и их частот.
7. Проверка редких категорий.
8. Построение корреляционной матрицы числовых признаков.
9. Анализ наиболее коррелирующих признаков с помощью диаграмм рассеяния.
10. Проверка целевой переменной и её распределения.

### Визуализация

В работе использованы:

- гистограммы;
- boxplot;
- столбчатые диаграммы;
- корреляционная матрица;
- диаграммы рассеяния.

Каждый график сопровождается текстовым выводом.

### Анализ проблем данных

В результате EDA были исследованы:

- пропущенные значения;
- дубликаты;
- потенциальные выбросы;
- распределение числовых признаков;
- редкие категории;
- корреляции между признаками;
- распределение целевой переменной.
